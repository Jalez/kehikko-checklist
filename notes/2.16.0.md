Kind: feature

- **Advice on test steps names the work queue you have installed.** When an agent is told that test runs and one-time steps do not belong on a checklist, it is now told where they go in the words of the work queue module that is installed, and told nothing about a queue when none is.

## For agents

- The tools' and the door's line about test steps names the installed work queue and its tool (for example "queue them in <name> (its <tool> tool)"); with no work queue installed, it only says they do not belong on a checklist.

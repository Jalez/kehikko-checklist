- **Tests pass, shown beside the lists.** When something on your computer runs the tests for an issue, merge request or pull request, Checklist shows "Tests pass: <what ran>" for it, one line per kind of run, saying whether it is queued, running, passed, failed or cancelled.
- **Ticked by the run, not by you.** The line is ticked while the newest run passed and unticked as soon as a newer one fails or starts again. Each line says it comes from a test run, and it has no box to press: to change it, run it again.
- **Hide the ones you do not need.** Hide takes a line away for that item and keeps it away through later runs. "Show 1 hidden" brings it back.
